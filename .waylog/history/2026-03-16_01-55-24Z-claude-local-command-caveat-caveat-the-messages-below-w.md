## "全部模型商"分类的实现逻辑

### 1. 分组来源

**`availableGroups` 计算逻辑**（`ui-lib.tsx` 行 621-633）：

```typescript
const availableGroups = (() => {
  // 1. 从所有模型的 item.group 字段收集不重复的分组名
  const groups = Array.from(
    new Set(props.items.map((item) => item.group?.trim()).filter(Boolean)),
  );
  
  // 2. 合并 extraGroups（如 "自定义模型"）
  const mergedGroups = Array.from(
    new Set([...groups, ...(props.extraGroups ?? [])]),
  );

  // 3. 排序：优先显示 preferredGroupOrder 中的，其余按原始顺序
  return [
    ...preferredGroupOrder.filter((group) => mergedGroups.includes(group)),
    ...mergedGroups.filter((group) => !preferredGroupOrder.includes(group)),
  ];
})();
```

const groupFilterOptions = ["All", ...availableGroups];

items={models.map((m) => ({

### 4. 分组决策优先级

`getModelGroup` 函数的优先级：
1. **`vendor?.name`** - 模型定义的供应商名称（最高优先级）
2. **`provider?.providerName`** + 关键字匹配 - 按服务商 ID 匹配关键字
3. **常见关键字** - claude、gpt、gemini、deepseek、qwen
4. **模型名称本身** - 兜底方案

### 5. 优先顺序列表

```typescript
const preferredGroupOrder = [
  "OpenAI", "DeepSeek", "Google", "Anthropic",
  "xAI", "ByteDance", "Qwen", "Moonshot",
  "Tencent", "Zhipu", "Minimax", "Microsoft", "Other"

```

### 总结

| 步骤 | 说明 |
|------|------|
| 1 | 遍历所有模型，提取 `item.group` 字段 |
| 2 | 合并 `extraGroups`（如"自定义模型"） |
| 3 | 按 `preferredGroupOrder` 排序，未列出的追加到后面 |
| 4 | 前置添加 "All" 选项（显示为"全部模型商"） |

所以"全部模型商"列表是**动态生成**的，取决于当前可用模型的 `vendor.name` 或 `getModelGroup` 返回值。
