### 1. 组件层 (`app/components/model-config.tsx`)
- **ModelConfigList**: 主模型配置组件
  - 使用 `useAllModels()` 获取可用模型
  - 按 **vendor.name** 分组（优先）或 **provider.providerName** 分组（降级）
  - 使用 `<Select>` + `<optgroup>` 渲染分组下拉菜单
  - 根据模型类型动态显示支持的参数

### 2. 数据获取层 (`app/utils/models.ts`)
- **fetchModelsFromProvider()**: 从各供应商 API 获取模型列表
  - 支持 OpenAI、Azure、Anthropic、DeepSeek、xAI 等
  - 支持 YutoAPI、AiHubMix、Ocoolai 等聚合平台
  - **AIHUBMIX_VENDOR_MAP**: developer_id 到供应商名称的映射表
  - **inferVendorFromModelName()**: 通过模型名前缀推断供应商

### 3. 数据处理层 (`app/utils/model.ts`)
- **collectModelsWithDefaultModel()**: 收集并排序模型
- **sortModelTable()**: 按 provider.sorted 和 model.sorted 排序
- **getModelProvider()**: 解析 `model@provider` 格式字符串

### 4. 状态管理 (`app/store/config.ts`)
- **useAppConfig**: 全局配置 store
  - `models`: LLMModel[] - 所有模型列表
  - `modelConfig`: 当前选中的模型配置
  - `mergeModels()`: 合并新旧模型（智能去重）

### 5. Hook (`app/utils/hooks.ts`)
- **useAllModels()**: 组合 `configStore.models` + `customModels` + `defaultModel`，返回可用模型列表
